# ST7789、microSD 与六键面板

开发版固件在 ESP32-S3 N16R8 上启用 240×320 ST7789、原生 1-bit SDMMC 和六个独立按键。LCD 使用 SPI3，像素数据通过 DMA 从内部 RAM 发送。microSD 使用 SDMMC 控制器的 DMA，SPI2 可继续用于高速 SWD。

| 外设 | 模块端信号 | ESP32-S3 |
| --- | --- | --- |
| ST7789 | SCK / SCL | GPIO12 |
| ST7789 | MOSI / SDA / DIN | GPIO11 |
| ST7789 | CS | GPIO15 |
| ST7789 | DC | GPIO16 |
| ST7789 | RST / RES | GPIO21 |
| ST7789 | BL / BLK | GPIO47 |
| microSD | CLK | GPIO14 |
| microSD | CMD | GPIO13 |
| microSD | DAT0 | GPIO10 |
| 按键 | 上 / 下 | GPIO1 / GPIO2 |
| 按键 | 左 / 右 | GPIO39 / GPIO40 |
| 按键 | 确认 / 返回 | GPIO41 / GPIO42 |

- 所有外设与板子共地，信号使用 3.3 V。LCD 的 SDA 是 SPI 数据输入，MISO 无需接线。GPIO47 默认高电平点亮，连接模块的背光控制端。裸屏背光 LED 需按规格使用限流和驱动电路。
- microSD 使用能直接接触原生 SD 信号的 3.3 V 卡座或模块。CMD 和 DAT0～DAT3 各用 10 kΩ 上拉到 3.3 V。DAT1～DAT3 只在卡座侧上拉，无需连接 ESP32 GPIO。CLK 直连，卡检测脚留空。
- 每个按钮一端接指定 GPIO，另一端接 GND。固件启用内部上拉与按下消抖。GPIO39～42 用于按键时，板上这组外接 JTAG 引脚不能同时使用。
- LCD 按 240×320 竖屏、SPI mode 0、20 MHz 和默认反色驱动。若背光极性或色彩与模块不符，可在 `idf.py menuconfig` 的本地面板菜单调整背光极性、反色及屏幕时钟。该菜单也可关闭整套面板。

## 离线烧录

1. 使用 FAT32 microSD，把 STM32 固件的 `.bin` 放在卡的根目录。面板显示最多 48 个文件，长文件名在屏幕上截短。
2. 为 STM32H743VI（2 MiB）目标板供电，接共地、SWCLK、SWDIO 和 NRST。退出电脑上的 SWD 调试会话。ESP-SWD 可用 USB 电源供电，烧录无需电脑或网络。
3. 选择「存储卡镜像」或「板载镜像」。上下移动，左右翻页，确认键打开文件。若开机时无卡，插卡后在「存储卡镜像」页按确认重试。
4. 在「烧录设置」中上下选择字段，左右修改地址和复位选项。默认起始地址为 `0x08000000`，以 128 KiB 扇区为单位选择。默认校验完成后保持目标暂停，按需改为「完成后复位运行」。
5. 在地址、复位或「继续烧录」行按确认进入烧录确认页。核对文件、地址、复位选项及实际擦除范围，再单独长按确认约 1 秒。最后一个涉及的扇区会整块擦除。ESP-SWD 自身的应用镜像会在访问 SWD 之前被拒绝。

## 保存到板载

从存储卡选中文件，在「烧录设置」选「保存到板载」并长按确认。保存通过内置 Flash 的 `offline` 分区保留一个可用镜像，写入和读回完成之前保留上一个镜像。以后打开「板载镜像」即可烧录，无需插卡。ESP-SWD 应用 OTA 继续使用独立 OTA 分区。

## 设备信息

「设备信息」显示局域网或热点地址、存储卡状态及按键计数。在该页按右键卸载存储卡，确认已卸载后再拔出。挂载失败时保留原卡内容，日志可在 CH343 UART 控制台查看。

打开网页配置窗口后，屏幕底部显示临时 `WEB` 配置码。见[网页配置说明](WEB_CONFIG.md)。屏幕的中文点阵从 Noto Sans SC 生成，随源码保留 [SIL Open Font License](../main/panel_assets/OFL.txt)。
