# 固件网页配置

0.1.4 将配置页存入应用镜像。浏览器可直接查看烧录器序列号、运行版本、网络连接和 IP 地址，并保存或清除路由器 Wi-Fi 设置。

1. 连接烧录器热点 `ESP-SWD`，打开 `http://192.168.4.1/`。烧录器已连路由器时，也可在同一局域网打开设备的当前 IPv4 地址。
2. 修改设置时，长按运行中的 BOOT 约 2 秒。LCD 顶部显示 12 位 `WEB:` 配置码。也可在 CH343 UART 控制台运行 `webcfg arm`，或用 `webcfg status` 查看现有配置码。`webcfg off` 立即关闭窗口。
3. 在网页输入配置码、目标 SSID 和密码，点击「保存并重启」。开放网络可留空密码。设置成功后会关闭窗口，设备约 2.5 秒后重启。配置清除也会重启。地址变化时重新连接设备热点，或查看路由器中设备的新地址。

每次授权生成新码，有效期 5 分钟。页面通过普通 HTTP 访问。填写路由器密码时请使用可信的本地网络，且不要将配置端口转发到公网。页面和状态响应不会返回 Wi-Fi 密码或配置码。网页只管理设备的网络配置，固件 OTA 仍使用各版发布目录的 `images/esp_swdlink.bin`。
