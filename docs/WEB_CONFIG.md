# 固件网页

固件 0.1.5 的内置网页提供设备状态、目标烧录、串口监视、ESP-SWD OTA 和 Wi-Fi 配置。

1. 首次联网时，使用 WireLink 的 USB 或加密 BLE 配网将烧录器接入路由器，再在同一局域网打开设备的 IPv4 地址。自行构建并启用热点时，也可连接设备热点后访问 `http://192.168.4.1/`。
2. 开始操作前，长按运行中的 BOOT 约 2 秒。LCD 底部显示 12 位 `WEB` 配置码。也可在 CH343 UART 控制台运行 `webcfg arm`，或用 `webcfg status` 查看现有配置码。`webcfg off` 立即关闭窗口。
3. 将配置码输入页面的「操作授权」。每次授权生成新码，有效期 5 分钟。页面使用 HTTP，请在可信本地网络使用，端口仅供局域网访问。

## 目标芯片烧录

支持采用标准双 Bank 映射的 STM32H743VI（2 MiB）。为目标板供电，连接 SWDIO、SWCLK、NRST 和 GND，先关闭 Keil、pyOCD 等工具的调试会话。

选择目标程序的 `.bin` 文件，填写与链接地址一致的烧录地址。默认地址为 `0x08000000`，起点须按 128 KiB 扇区对齐。网页会要求确认擦除范围，最后一个受影响的扇区也会整块擦除。固件仅在完整接收文件后启动烧录，写入后逐字节读回校验。默认将目标保持在暂停状态，勾选「校验通过后复位运行」即可在成功后启动目标程序。

ESP-SWD 自身的应用镜像请在「ESP-SWD 固件 OTA」上传。目标烧录入口会识别并拒绝该镜像。

## 目标串口监视

连接目标 UART TX 至烧录器 UART RX 并共地，确认波特率匹配。在网页点击「开始监视」，即可用 UTF-8 查看收到的数据和当前波特率。网页与 USB、TCP 和 BLE 串口桥可同时读取。刷新速度跟不上输入时，网页会显示缓冲区覆盖的字节数。

## ESP-SWD 固件 OTA

选择应用镜像 `esp_swdlink.bin`，可使用 `idf.py build` 生成的 `build/esp_swdlink.bin`，或对应更新包的 `images/esp_swdlink.bin`。上传完成后，ESP-SWD 将镜像写入备用 OTA 槽位，校验后重启。网页会核对实际运行的镜像和启动确认状态。如果网络地址改变，重新打开设备的新地址查看状态。现有 USB、BLE 和 Wi-Fi OTA 与网页共用更新任务，一次只执行一项。

## 配置 Wi-Fi

点击「扫描附近 Wi-Fi」，从 2.4 GHz 网络列表选取路由器，网页会自动填写 SSID。列表显示信号强度、信道及加密状态。隐藏网络可以手动输入 SSID。

输入路由器的密码，点击「保存并重启」。开放网络可留空密码。保存或清除配置会关闭授权窗口，设备约 2.5 秒后重启。地址变化时重新连接设备热点，或查看路由器中设备的新地址。
